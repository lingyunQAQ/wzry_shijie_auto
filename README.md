## 📖 项目介绍

这是一个基于OCR文字识别的自动化监控脚本，专为王者荣耀世界游戏设计。程序会持续监控屏幕指定区域，当检测到目标文字（如"点击前往"）时，自动执行快速点击操作，帮助玩家快速响应游戏内的各种提示。

### 主要用途

- 自动检测游戏内的文字提示
- 检测到目标后立即执行多次快速点击
- 适用于需要快速响应的游戏场景
- 可自定义检测区域、点击次数等参数

### 功能特点

- ⚡ **极速检测**：最快0.01秒检测一次，响应迅速
- 🎯 **精准识别**：基于Tesseract OCR引擎，支持中文识别
- 🖱️ **快速点击**：检测到后瞬间完成多次点击（可配置）
- 🔧 **灵活配置**：提供图形化配置工具，轻松设置检测区域
- 🔊 **音频提醒**：点击成功后播放提示音（可选）
- 📝 **日志记录**：完整的操作日志，方便问题排查
- 🚀 **自动退出**：点击成功后自动退出程序

## 🛠️ 安装方法

### 前置要求

- **Python 3.7+**
- **Windows 操作系统**（音频功能仅支持Windows）
- **Tesseract-OCR 引擎**

### 步骤 1：安装 Tesseract-OCR

1. 下载 Tesseract-OCR 安装包：
   - 官方下载：https://github.com/UB-Mannheim/tesseract/wiki
   - 推荐版本：5.0 或更高

2. 安装到默认路径：`C:\Program Files\Tesseract-OCR\`
   - 如果安装到其他路径，需要在代码中修改路径配置

3. 确保安装时勾选了**中文语言包（chi_sim）**

### 步骤 2：安装 Python 依赖

在项目目录下执行：

```bash
pip install -r requirements.txt
```

这将自动安装以下依赖：
- `pytesseract` - OCR识别引擎接口
- `Pillow` - 图像处理库
- `pyautogui` - 自动化操作库
- `pygetwindow` - 窗口管理库

### 步骤 3：配置检测区域

运行图形化配置工具：

```bash
python config_gui.py
```

配置步骤：
1. 点击"选择区域"按钮
2. 在屏幕上拖动鼠标框选包含目标文字的区域
3. 调整其他参数（点击次数、检测间隔等）
4. 点击"保存配置"按钮

**提示**：检测区域越小，识别速度越快，建议只框选必要的区域。

### 步骤 4：启动监控

配置完成后，运行主程序：

```bash
python main.py
```

程序将开始监控指定区域，检测到目标文字后自动点击并退出。

## ⚙️ 配置说明

### 配置文件

程序的所有配置保存在 `config.json` 文件中，你可以直接编辑此文件或使用图形化工具修改。

### 主要参数

| 参数 | 说明 | 默认值 | 推荐值 |
|------|------|--------|--------|
| `detection_area` | 检测区域（x, y, width, height） | - | 尽量小 |
| `target_text` | 要检测的目标文字 | "点击前往" | 根据需要修改 |
| `loop_interval` | 检测间隔（秒） | 0.01 | 0.01-0.1 |
| `click_count` | 检测到后点击次数 | 10 | 5-20 |
| `click_interval` | 每次点击间隔（秒） | 0.01 | 0.01 |
| `similarity_threshold` | 文字相似度阈值 | 0.8 | 0.7-0.95 |
| `enable_sound` | 是否播放提示音 | true | true/false |
| `fast_mode` | 快速模式（减少输出） | true | true |

### 配置示例

```json
{
    "detection_area": {
        "x": 538,
        "y": 587,
        "width": 812,
        "height": 352
    },
    "click_offset": {
        "x": 0,
        "y": 0
    },
    "target_text": "点击前往",
    "similarity_threshold": 0.8,
    "loop_interval": 0.01,
    "click_count": 10,
    "click_interval": 0.01,
    "enable_sound": true,
    "fast_mode": true
}
```

## ❓ 常见问题

### Q1: 提示找不到 Tesseract 或识别失败

**原因**：Tesseract-OCR 未正确安装或路径不对

**解决方案**：
1. 确认已安装 Tesseract-OCR
2. 检查安装路径是否为 `C:\Program Files\Tesseract-OCR\tesseract.exe`
3. 如果安装在其他路径，修改 `modules/ocr.py` 第30-31行的路径配置
4. 确保安装时选择了中文语言包（chi_sim）

### Q2: 识别不到目标文字

**原因**：检测区域设置不当或文字不清晰

**解决方案**：
1. 使用配置工具重新选择检测区域，确保目标文字完整包含在内
2. 缩小检测区域，只包含必要的文字区域
3. 降低 `similarity_threshold` 值（如从0.8降到0.6）
4. 确保游戏画面清晰，文字可见
5. 检查 `logs/monitor.log` 查看OCR识别到的文字内容

### Q3: 点击位置不准确

**原因**：点击偏移量设置不当

**解决方案**：
1. 在配置文件中调整 `click_offset` 的 x 和 y 值
2. 正值向右/下偏移，负值向左/上偏移
3. 建议每次调整5-10像素，逐步测试

### Q4: 程序运行速度太慢

**原因**：检测区域过大或配置不当

**解决方案**：
1. **最重要**：缩小检测区域，这是影响速度的最大因素
2. 建议检测区域大小：300x100 像素左右
3. 确保 `fast_mode` 设置为 `true`
4. 适当增加 `loop_interval`（如0.05-0.1秒）

### Q5: 点击次数不对，总是固定10次

**原因**：配置文件中缺少 `click_count` 参数（已修复）

**解决方案**：
1. 确保 `config.json` 中包含 `click_count` 参数
2. 使用配置工具重新保存配置
3. 或手动在配置文件中添加：`"click_count": 你想要的次数`

### Q6: 没有声音提示

**原因**：音频功能被禁用或系统不支持

**解决方案**：
1. 检查 `config.json` 中 `enable_sound` 是否为 `true`
2. 音频功能仅支持 Windows 系统
3. 确保系统音量未静音

### Q7: 如何查看详细的运行日志？

**解决方案**：
1. 日志文件位置：`logs/monitor.log`
2. 日志包含所有检测、识别、点击操作的详细信息
3. 快速模式下屏幕输出较少，但日志仍会完整记录

## 💡 使用技巧

1. **优化检测速度**：
   - 检测区域越小越好，只框选必要区域
   - 推荐区域大小：300x100 到 500x200 像素
   - 避免包含过多无关文字

2. **提高识别准确率**：
   - 确保目标文字清晰可见
   - 适当调整相似度阈值（0.7-0.95之间）
   - 避免检测区域包含相似的干扰文字

3. **调整点击行为**：
   - 根据实际需要设置点击次数（5-20次）
   - 点击间隔通常保持0.01秒即可
   - 如需更快响应，可降低 `loop_interval` 到0.01秒

4. **调试技巧**：
   - 首次使用建议关闭快速模式，观察识别过程
   - 查看日志文件了解OCR识别到的所有文字
   - 逐步调整参数，每次只改一个参数

## ⚠️ 注意事项

1. **检测区域设置**：
   - 区域越小，识别速度越快
   - 建议只包含目标文字及周边少量区域
   - 避免包含大量动态变化的内容

2. **系统要求**：
   - 需要 Windows 操作系统（音频功能）
